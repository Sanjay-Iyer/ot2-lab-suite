# Archive

Historical source is preserved for reference, outside the active Python modules.

- `legacy_agents/`: four dated agent/stress-test implementations formerly in
  `src/agents/archive/`. No active Python/YAML references were found; the old
  documentation tree is preserved in the documentation archive. Bytes are unchanged.
- `documentation/README.before-agent-reorganization.md`: the former documentation
  landing page, preserved before replacing it with a concise index.
- `documentation/AI_Agent_Overview.before-agent-reorganization.md`: the older
  LangChain/vial-agent overview; its former URL now points to the primary demo.
- `agent_nanodrop_strict_rules_20260929/`: existing historical snapshot, retained.

Archived programs are reference material, not recommended operating commands.
Old protocol families remain at their existing paths because current registries
and experimental configurations still reference them. Earlier redesign reviews,
inactive patches and uncommitted recovery work remain in `docs/reviews/`.
The current reorganization supersedes that review process; it does not claim its
unfinished tasks passed.
