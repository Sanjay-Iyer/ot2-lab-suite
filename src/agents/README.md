# AI agents

**Primary:** [Agent NanoDrop](dye_demo/README.md), launched through the top-level
NiceGUI/terminal scripts. Its current Skills and Memory remain unchanged.

**Optional:** [other agent families](optional/README.md). These retain independently
useful general-workflow, labware-generation, registered-printing and older vial
demo interfaces. They are not replaced by NanoDrop or described as obsolete.

Two historical simulation/stress harnesses were archived externally in cleanup
batch C2. They are not current regression commands. See the
[cleanup manifest](../../docs/cleanup/README.md) for restoration and provenance.
