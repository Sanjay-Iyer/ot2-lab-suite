# Legacy compatibility protocols

These seven templates remain addressable by builder IDs1,2,3,4,6,7,8. They retain
unique historical P20/P300, nozzle-layout, dilution and printing behavior and are
not replaced by NanoDrop. Source bytes are identical to their pre-cleanup files.
The registry, builder default and validator fallback paths point here.

They are optional compatibility methods, not the primary demo. Original source
headers are preserved as historical method documentation. External cleanup batch
C3a stores independently verified original copies and original-path metadata.
